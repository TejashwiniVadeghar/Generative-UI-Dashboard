# Generative-UI-Dashboard
📊 AI Visual Dashboard (Generative UI)

An interactive web application that transforms natural-language prompts into dynamic, animated bar charts using **Google Gemini AI** and **Tailwind CSS**.

🔗 **[View Live Demo]([https://github.io](https://tejashwinivadeghar.github.io/Generative-UI-Dashboard/))**

---

## ✨ Key Features
* **Generative UI Output:** Converts plain-English queries into structured JSON data and renders animated visual charts in real time.
* **Built-in Demo Mode:** Includes a one-click **✨ Try Demo Mode** button so visitors can preview the interactive UI without needing an API key.
* **Client-Side Key Security:** Uses a local password input field for API keys—no secret keys are stored or exposed in the repository.
* **Zero-Build Architecture:** Runs directly in the browser with zero backend server costs.

## 🛠️ Tech Stack
* **Frontend:** HTML5, Vanilla JavaScript (ES6+), Tailwind CSS
* **AI Model:** Google Gemini (`gemini-2.5-flash` via REST API with Structured JSON output)
* **Hosting:** GitHub Pages

## 🚀 How to Use
1. Open the **[Live Demo]([https://github.io](https://tejashwinivadeghar.github.io/Generative-UI-Dashboard/))**.
2. Click **✨ Try Demo Mode** for an instant preview, **or** paste your free API key from [Google AI Studio](https://google.com) and type any topic (e.g., *"Top 4 renewable energy sources"*).
